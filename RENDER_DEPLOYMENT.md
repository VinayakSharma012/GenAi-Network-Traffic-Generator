# Render Deployment Guide - GenAI Network Traffic Generator

## Quick Start

### Prerequisites
- GitHub account with repository containing the project
- Render.com account (free tier available)
- Basic understanding of environment variables and web services

---

## Step-by-Step Deployment

### 1. Prepare Your Repository

Make sure your GitHub repository includes:
- `render.yaml` (already provided)
- `.env.example` (already provided)
- All source code and dependencies

```bash
# Push your code to GitHub
git add .
git commit -m "Prepare for Render deployment"
git push origin main
```

### 2. Create Backend Service on Render

1. Go to https://dashboard.render.com
2. Click **"New +"** → **"Web Service"**
3. Connect your GitHub repository
4. Configure the service:
   - **Name**: `genai-network-traffic-generator-backend`
   - **Runtime**: Python 3
   - **Build Command**: `cd backend && pip install -r requirements.txt`
   - **Start Command**: `cd backend && gunicorn --bind 0.0.0.0:10000 --workers 2 --timeout 120 api:app`
   - **Plan**: Free (or higher for production)

5. Add Environment Variables:
   - `FLASK_ENV` = `production`
   - `PYTHONUNBUFFERED` = `1`

6. Click **"Create Web Service"**
7. Wait for deployment to complete (5-10 minutes)
8. Copy the service URL (e.g., `https://genai-network-traffic-generator-backend.onrender.com`)

### 3. Create Frontend Service on Render

1. In Render dashboard, click **"New +"** → **"Static Site"**
2. Connect your GitHub repository
3. Configure the service:
   - **Name**: `genai-network-traffic-generator-frontend`
   - **Build Command**: `cd frontend && npm install && npm run build`
   - **Publish Directory**: `frontend/dist`

4. Add Environment Variable:
   - `VITE_API_URL` = `https://genai-network-traffic-generator-backend.onrender.com` (or your backend URL)

5. Click **"Create Static Site"**
6. Wait for build to complete (3-5 minutes)
7. Your frontend will be live at the generated Render URL

## Configuration Details

### Backend Service

**Port Configuration:**
- Render assigns a dynamic port; Gunicorn binds to 10000
- The `--bind 0.0.0.0:10000` flag is important for cloud environments

**Worker Configuration:**
- `--workers 2`: Appropriate for free tier; increase to 4+ for production
- `--timeout 120`: 2-minute timeout for long-running traffic generation

**Environment Variables:**
```env
FLASK_ENV=production           # Disables debug mode
PYTHONUNBUFFERED=1            # Real-time logging to stdout
```

### Frontend Service

**Build Output:**
- Output directory is `frontend/dist` (generated by Vite)
- Vite automatically includes all assets and HTML

**Environment Variables:**
```env
VITE_API_URL=https://your-backend-url.onrender.com
```

The frontend uses this variable to connect to the backend API:
```javascript
const API_URL = import.meta.env.VITE_API_URL || 'http://localhost:5000';
```


Expected response:

1. Click **DOWNLOAD** button

## Monitoring and Debugging

### View Logs

1. Go to Render dashboard
2. Click on your service
3. Select **"Logs"** tab
4. Monitor real-time output

### Common Issues

**502 Bad Gateway**
- Backend not responding
- Check if service crashed (Logs tab)
- Verify PYTHONUNBUFFERED=1 is set

**CORS Errors in Browser**
- Frontend and backend URLs mismatch
- Update VITE_API_URL environment variable
- Restart frontend service

**Module Not Found Errors**
- Run backend build command manually:
  ```bash
  cd backend && pip install -r requirements.txt
  ```
- Ensure all dependencies are in `requirements.txt`

**Traffic Generation Fails**
- Check if backend has sufficient system resources
- Verify Flask service is running with `ps aux | grep gunicorn`
- Check backend logs for error messages

## Performance Optimization

### For Production

1. **Backend Workers**: Increase from 2 to 4-8
   ```
   --workers 4
   ```

2. **Database Caching** (if added later):
   - Use Redis (available as Render add-on)
   - Cache log queries

3. **Frontend CDN**:
   - Render automatically serves static files via CDN
   - Ensure `frontend/dist` is generated correctly

4. **Environment Optimization**:
   ```env
   FLASK_ENV=production
   FLASK_DEBUG=0
   ```

## API Reference (Production URLs)

Replace `BASE_URL` with your backend URL:

```
GET BASE_URL/api/health
```

```
POST BASE_URL/api/traffic/start

  "dns_count": 100,

  "smtp_count": 50,
  "ftp_host": "ftp.example.com",
```

```
POST BASE_URL/api/traffic/stop
```

```
GET BASE_URL/api/logs
```

## Cleanup and Deactivation

To remove services from Render:

1. Go to Render dashboard
2. Select service → **Settings** → **Delete Service**
3. Confirm deletion

⚠️ **Note**: Deleting a service removes its URL and all associated data.
